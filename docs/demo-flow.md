# LinkFluence Hackathon Demo

1. Open the LinkFluence homepage.
2. Explore the creator directory.
3. Open a creator profile.
4. Navigate to Create Campaign.
5. Enter brand and campaign details.
6. Submit the campaign brief.
7. Review the ranked creator recommendations.
8. Open a recommendation to inspect the creator profile.
9. Return to the dashboard to review saved campaigns.

Main demonstration feature:
Explainable creator-to-campaign matching.
